# Daggerheart Session Zero

Guide a DM through running session zero with their players.

## When to Use

- Starting a new campaign with a group
- Need to establish table expectations
- Coordinating character creation
- Weaving backstories together

## Prerequisites

Read `campaign/concept.md` for campaign context.

## Quick Reference

| Step | Purpose |
|------|---------|
| Safety tools | Establish lines, veils, X-card |
| Expectations | Frequency, attendance, PvP, death |
| Characters | Create party with role variety |
| Backstories | Tie characters to setting and each other |
| Starting situation | Where session 1 begins |

## Process

### 1. Safety Tools

Remind DM to establish:
- **Lines** - Topics completely off the table
- **Veils** - Topics that happen "off-screen"
- **X-Card** - Anyone can pause if uncomfortable
- **Open Door** - Players can step away anytime

Ask if they want help explaining these.

### 2. Table Expectations

Discuss and document:
- Session frequency and length
- Attendance expectations
- Communication preferences
- PvP rules (allowed? consent required?)
- Character death handling
- Tone reinforcement (from campaign concept)

### 3. Character Creation

Guide the group:
1. Share campaign pitch
2. Discuss party role needs
3. Create characters (use `daggerheart-character` skill)
4. Ensure variety (not all same class)

Use `search_rules` for "Character Creation" reference.

### 4. Weave Backstories

For each character:
- How do they connect to the setting?
- Ties to any factions?
- What brings them into the story?
- How do they know other PCs?

Look for opportunities to tie backstories to campaign conflict.

### 5. Establish Starting Situation

Help DM establish:
- Where do characters meet?
- What brings them together?
- What's the first hook?

```markdown
|--------|-----------|-------|
| ... | ... | ... |

How each character ties to setting and conflict

## Starting Situation
Where and how session 1 begins
```

## Common Mistakes

- **Skipping safety tools**: Always establish them, even with friends.
- **No party coordination**: Avoid 4 rogues or no healer.
- **Isolated backstories**: Every character should connect to something.
