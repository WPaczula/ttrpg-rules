# Daggerheart Arc Planning

Plan a story arc spanning 3-5 sessions within a Daggerheart campaign.

## When to Use

- DM wants to plan a multi-session storyline
- Need to structure content between campaign start and climax
- Designing a focused mini-arc (new threat, backstory resolution, location exploration)

## Prerequisites

Read campaign context first:
- `campaign/concept.md` - campaign overview
- `campaign/arcs/` - existing arcs

## Quick Reference

| Element | Purpose |
|---------|---------|
| **Opening Hook** | Draws players in |
| **Rising Action** | 2-3 challenges/discoveries |
| **Climax** | Big confrontation or choice |
| **Resolution** | Consequences + next arc setup |

## Process

### 1. Define Arc Goal

Ask what this arc accomplishes:
- Introduce threat/faction
- Advance villain's plan
- Resolve backstory thread
- Explore new location
- Build NPC relationships

### 2. Structure Sessions

Plan the arc shape - not every session, just beats:
- Hook → Challenges → Climax → Resolution

### 3. Design Key Scenes

For each major scene: What happens? What's the conflict? What's at stake?

### 4. Select Adversaries

Use MCP tools:
- `search_rules` - find thematically appropriate enemies
- `list_adversaries` - filter by tier for party level

Make fights interesting: terrain, objectives, time pressure.

### 5. Plan Decision Points

Identify 2-3 meaningful choices:
- What are the options?
- What are consequences?
- How do choices affect the campaign?

## Output

Save to `campaign/arcs/arc-N-title.md`:

```markdown
# Arc Title

**Goal:** What this arc accomplishes
**Sessions:** Estimated count

## Opening
How it begins

## Key Scenes
- Scene 1: ...
- Scene 2: ...

## Adversaries
Which enemies appear and why

## Decision Points
Major choices and their consequences

## Resolution Options
How it might end
```

## Common Mistakes

- **Over-planning**: Don't script every moment. Plan beats, not dialog.
- **Linear paths**: Always have 2+ ways scenes can go.
- **Ignoring player backstories**: Best arcs tie to character histories.
